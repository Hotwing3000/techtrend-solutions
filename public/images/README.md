# Images

Drop your images in this folder. Reference them in code as `/images/filename.jpg`
(no `public/` prefix).

Suggested filenames matching current placeholders:

- `hero.jpg` — landing page hero
- `team.jpg` — "team in meeting with client"
- `founders.jpg` — Jonathan and Camilla
- `mission.jpg` — team collaboration shot
- `service-firewall.jpg` etc. — service section illustrations
- `blog-firewall.jpg` — "What is a firewall" post header
- `blog-vulnerable.jpg` — "5 signs you're vulnerable"
- `blog-gdpr.jpg` — GDPR post
- `blog-ransomware.jpg` — ransomware post

Recommended formats: `.jpg` for photos, `.png` for illustrations with transparency,
`.webp` for best compression. Next.js `<Image>` will serve modern formats automatically.
